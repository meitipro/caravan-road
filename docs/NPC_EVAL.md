## Read this first

> **FAKE MODEL.** Every model-driven row in this document comes from a scripted heuristic, not from a language model. In the underlying records `Decision.source` reads `llm` only because the schema has no other value; the records carry `model = fake-scripted`, request ids `fake-*` and `attested = false`. None of it is real inference evidence.

- The model used for every table below is **fake-scripted**: a scripted heuristic with optional injected faults (src/fake/fake-model.ts). It is **not a language model**. These tables measure this repository's validation, clamping, retry, fallback and simulation plumbing. They say nothing about how a real model on NEAR AI Cloud behaves.
- The simulation uses the worker's own in-memory world (src/sim-world.ts), not the Appendix B reference simulation. Numbers are comparable only with other rows of this document (same seeds, same bots), never with spec/ECONOMY.md section 2.9.
- Prices use `MULT_K_BP = 3000` from packages/shared (spec-v1.2: 3000; spec-v1.1: 4000). Every table below (the synthetic states in A and the simulations in B) was generated with that value, so the numbers differ from a file generated under spec-v1.1.
- No latency figure is given for the fake model, because there is no network to measure.
- Real-model results: **not run**. They require a NEAR_AI_API_KEY and a model choice (see docs/WORKER.md). The harness supports them with `--real`.
