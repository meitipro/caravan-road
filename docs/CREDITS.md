# Credits and asset provenance

## Sprites and art

Every image under `apps/web/public/assets/` (map, city banners, merchant
portraits, goods icons, caravan sheet, coin, guard, logo) was generated by code in
[`tools/art/`](../tools/art) (Python 3 + Pillow). Nothing was drawn in an external
editor, downloaded, traced, or produced by an image model, and no third-party
art pack is used. Run `python tools/art/build.py` to regenerate them; the output
is deterministic (seeded) and `tools/art/tests` checks that every pixel is one of
the 12 palette colours (spec-v1 section 2.15) or transparent, that sizes are
exact, and that the committed PNGs match the generator.

- Generated on: **2026-10-30 (UTC, from `date -u`)**, before the NEAR HACKATHON
  build window (2026-11-01T00:00:00Z to 2026-11-14T23:59:00Z) opened.
  These sprites were therefore NOT created during the hackathon window; they are
  an initial version produced by the pipeline ahead of it. Any later
  regeneration or edit will show up in git history.
- Commit range: first introduced in `78f0972` ("feat(art): palette-strict art
  pipeline and all asset slots ...", branch `chore/scaffold`); later changes to
  `tools/art/`, `apps/web/public/assets/` are listed by
  `git log --oneline -- tools/art apps/web/public/assets docs/CREDITS.md`.
- Author: generated with Claude Code (an AI coding assistant) at the direction
  of the project owner; the art is original to this repository.

## Fonts

- **Sprite pipeline (`tools/art`)**: no font file is used. The 5x7 pixel
  lettering in the logo and in the contact-sheet labels comes from a small glyph
  table typed by hand for this repository (`tools/art/font5x7.py`, plain 5x7 dot
  grids for A-Z, 0-9 and a little punctuation). It contains no third-party font
  data, so there is no font license to attribute.
- **Web UI fonts** (loaded via `next/font` in `apps/web`) are chosen by the UI
  phase and are NOT covered by this file yet. Whoever adds them must record each
  font's name, license (verified from its own LICENSE file) and URL here.
  Status: not yet recorded.
